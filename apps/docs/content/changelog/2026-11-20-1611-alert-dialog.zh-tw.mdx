#### 元件

- **Alert Dialog（新增）：** 用在使用者必須回應才能繼續的動作（例如刪除）的模態確認視窗。建立在 Base UI Alert Dialog 上，role 是 `alertdialog`，點擊外部不會關閉。組法和 `Dialog` 相同（trigger、portal、backdrop、viewport、popup），另有 `AlertDialogBody`、放狀態圖示的 `AlertDialogMedia`、`AlertDialogHeader`、`AlertDialogTitle`、`AlertDialogDescription`、`AlertDialogFooter` 與 `AlertDialogClose`。`AlertDialogPortal` 可傳 `container` 放進別的節點。用 `@vital-design/alert-dialog` 安裝。
