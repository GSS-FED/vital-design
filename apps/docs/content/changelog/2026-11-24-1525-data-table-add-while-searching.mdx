---
title: Data Table shows the row you just added
---

Adding a row while searching looked like it did nothing: the search filtered the new row out. Now 新增 clears the search and opens the group the row lands in, so the new row shows right away, ready to edit.

```bash
npx shadcn@latest add @vital-design/data-table
```

If you changed your copy, bring over the changes in `data-table.tsx` (`addRow`) and `group-tree.ts` (`groupIdsOf`).

See [Data Table](/docs/blocks/data-table).
