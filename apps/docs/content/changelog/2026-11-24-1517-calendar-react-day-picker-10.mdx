---
title: Calendar requires react-day-picker 10
---

#### Components

- **Calendar:** now installs `react-day-picker@^10.0.2` instead of whichever version is latest, and no longer fails type checking on version 10 (`'table' does not exist in type 'Partial<ClassNames>'`). The removed `table` class name had no effect, so the calendar looks the same.

  Reinstall `calendar` to pick this up. If your project uses `react-day-picker` 9, this upgrades it to 10, which removed deprecated props such as `fromYear` and `toYear`; check the [upgrade guide](https://daypicker.dev/upgrading) if you pass react-day-picker props through `Calendar` or use the package elsewhere.

  `calendar` no longer adds `date-fns` to your project, because the component does not import it. If your own code imports `date-fns`, as the date picker example does, install it yourself.
