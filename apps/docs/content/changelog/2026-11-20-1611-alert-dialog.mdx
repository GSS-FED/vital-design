#### Components

- **Alert Dialog (new):** a modal confirmation for actions the user must answer before continuing, such as deleting something. It is built on Base UI Alert Dialog, so it has `role="alertdialog"` and doesn't close on an outside click. It composes like `Dialog` (trigger, portal, backdrop, viewport, popup), with `AlertDialogBody`, `AlertDialogMedia` for a status icon, `AlertDialogHeader`, `AlertDialogTitle`, `AlertDialogDescription`, `AlertDialogFooter`, and `AlertDialogClose`. `AlertDialogPortal` takes `container` to render inside another node. Install it with `@vital-design/alert-dialog`.
