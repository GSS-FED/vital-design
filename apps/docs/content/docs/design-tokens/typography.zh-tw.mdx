## 字型家族

Vittal Design 透過 `--font-sans` 提供一組無襯線字型，並註冊成 Tailwind 的 `font-sans` token。

```css
--font-sans:
  Roboto,
  'Noto Sans TC',
  'PingFang TC',
  'Microsoft JhengHei',
  sans-serif;
```

這組字型的順序是：

1. **Roboto** — 拉丁字母與介面文字
2. **Noto Sans TC** / **PingFang TC** / **Microsoft JhengHei** — 繁體中文的後備字型

```html
<p class="font-sans">Vittal Design 元件庫</p>
```

<div className="not-prose my-4 rounded-md border border-grayscale-opacity-200 bg-white p-6">
  <p className="font-sans text-base text-grayscale-opacity-900">
    Vittal Design 元件庫 — Roboto, 你好, 1234567890
  </p>
</div>

## 文字顏色

Vittal Design 的灰階用漸進透明度，同一組文字 token 在淺色與帶色背景上都讀得一致。依用途使用語意 `--text-*` token；需要精確控制對比時，直接選灰階。

| 用途           | 語意                             | 灰階                         |
| -------------- | -------------------------------- | ---------------------------- |
| 主要內容       | `text-(--foreground)`            | `text-grayscale-opacity-900` |
| 內文           | —                                | `text-grayscale-opacity-800` |
| 次要文字       | `text-(--muted-foreground)`      | `text-grayscale-opacity-700` |
| 淡文字         | `text-(--text-tertiary)`         | `text-grayscale-opacity-600` |
| 佔位文字       | `text-(--text-disabled)`         | `text-grayscale-opacity-400` |
| 強調背景上的字 | `text-(--primary-foreground)`    | —                            |

<div className="not-prose my-4 grid gap-2 rounded-md border border-grayscale-opacity-200 bg-white p-6">
  <p className="text-base text-grayscale-opacity-900">主要內容 — grayscale-opacity-900</p>
  <p className="text-base text-grayscale-opacity-800">內文 — grayscale-opacity-800</p>
  <p className="text-base text-grayscale-opacity-700">次要文字 — grayscale-opacity-700</p>
  <p className="text-base text-grayscale-opacity-600">淡文字 — grayscale-opacity-600</p>
  <p className="text-base text-grayscale-opacity-400">佔位文字 — grayscale-opacity-400</p>
</div>
