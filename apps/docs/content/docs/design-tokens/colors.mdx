## Overview

All colors are defined as CSS custom properties on `:root` and
mapped to Tailwind utilities via `@theme inline` in
`src-v2/styles/globals.css`. Use them as `var(--primary-500)` in CSS
or `bg-primary-500` / `text-primary-500` / `border-primary-500` in
Tailwind.

```ts
// 3 layers, generated from tokens/*.json by Style Dictionary
primitive  →  semantic  →  component
```

The primary palette is a blue scale used for interactive elements,

## Grayscale

The grayscale palette uses `rgba(35, 35, 50, α)` so it tonally adapts
over any background. `--grayscale-900` is the only solid hex.

## Avatar Palette

Each named avatar color exposes three tokens — `color` (text /
initials), `border`, and `bg`. Used by `AvatarRoot color="…"`.

<AvatarPalette tokens={avatarTokens} />

```css
background: var(--avatar-tiffany-bg);
border-color: var(--avatar-tiffany-border);
color: var(--avatar-tiffany-color);
```

## Tag Palette

Each named tag color exposes `solid` (text / icon) and `tint`
(background). Used by `Tag color="…"`.

<TagPalette tokens={tagTokens} />

```css
background: var(--tag-teal-tint);
color: var(--tag-teal-solid);
```
