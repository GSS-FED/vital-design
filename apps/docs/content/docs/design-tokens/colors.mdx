## Overview

All colors are defined as CSS custom properties in `:root` and mapped to Tailwind utility classes via `@theme inline`. This means you can use them both as `var(--primary-500)` in CSS and as `text-primary-500` / `bg-primary-500` in Tailwind.

## Semantic Colors

Four semantic palettes for status communication.

### Success
`#2BCD86` base — green scale for positive feedback.

### Info
`#00C3FF` base — cyan scale for informational messages.

### Warning
`#FFA700` base — amber scale for caution states.

### Alarm
`#EB5000` base — orange-red scale for errors and destructive actions.

Each semantic palette has `100–900` steps following the same naming convention:
```css
var(--success-500)   /* base */
var(--warning-100)   /* light tint */
var(--alarm-900)     /* dark shade */
```

## Shadows

Shadow tokens are defined in `@theme inline` and available as Tailwind utilities:

| Token | Usage |
|-------|-------|
| `--shadow-accent` | Subtle element shadow |
| `--shadow-base` | Default card shadow |
| `--shadow-emphasis` | Elevated panel shadow |
| `--shadow-top-level` | Modal / top-level overlay shadow |
| `--shadow-focus-primary` | Primary focus ring |
| `--shadow-button-primary` | Primary button hover shadow |

```css
.card {
  box-shadow: var(--shadow-base);
}
.card:focus-visible {
  box-shadow: var(--shadow-focus-primary);
}
```
