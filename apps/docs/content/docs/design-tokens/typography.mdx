## Font Family

Vital Design ships a single sans-serif stack via the `--font-sans`
CSS variable, registered as the Tailwind `font-sans` token.

```css
--font-sans:
  Roboto,
  'Noto Sans TC',
  'PingFang TC',
  'Microsoft JhengHei',
  sans-serif;
```

The stack prioritises:

1. **Roboto** — Latin / UI text
2. **Noto Sans TC** / **PingFang TC** / **Microsoft JhengHei** —
   Traditional Chinese fallbacks

```html
<p class="font-sans">Vital Design 元件庫</p>
```

<div className="not-prose my-4 rounded-md border border-grayscale-200 bg-white p-6">
  <p className="font-sans text-base text-grayscale-900">
    Vital Design 元件庫 — Roboto, 你好, 1234567890
  </p>
</div>

## Text Color

Vital Design's grayscale palette uses progressive transparency, so
the same text token reads consistently on light and tinted
backgrounds. Use the semantic `--text-*` tokens for intent, or pick
a grayscale step directly when you need exact contrast control.

| Usage           | Semantic                     | Grayscale step       |
| --------------- | ---------------------------- | -------------------- |
| Primary content | `text-(--foreground)`      | `text-grayscale-900` |
| Body / paragraph| —                            | `text-grayscale-800` |
| Secondary text  | `text-(--muted-foreground)`    | `text-grayscale-700` |
| Muted text      | `text-(--text-tertiary)`     | `text-grayscale-600` |
| Placeholder     | `text-(--text-disabled)`     | `text-grayscale-400` |
| On accent bg    | `text-(--primary-foreground)`    | —                    |

<div className="not-prose my-4 grid gap-2 rounded-md border border-grayscale-200 bg-white p-6">
  <p className="text-base text-grayscale-900">Primary — grayscale-900</p>
  <p className="text-base text-grayscale-800">Body — grayscale-800</p>
  <p className="text-base text-grayscale-700">Secondary — grayscale-700</p>
  <p className="text-base text-grayscale-600">Muted — grayscale-600</p>
  <p className="text-base text-grayscale-400">Placeholder — grayscale-400</p>
</div>
