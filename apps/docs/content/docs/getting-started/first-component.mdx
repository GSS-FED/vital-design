## Example: Button

Once installation and Tailwind setup are complete, import a component and use it:

> These examples assume you installed components through the registry and are importing the copied local files generated by your `components.json` aliases.

```tsx
import { Button } from '@/components/ui/Button';

// shadcn CLI path

export default function App() {
  return (
    <Button
      theme="primary"
      size="lg"
      onClick={() => alert('Hello!')}
    >
      Get Started
    </Button>
  );
}
```

If you are maintaining an existing npm-based integration, import from the package entry instead for the components that are available there:

```tsx
import { Button } from '@fed/vital-design';
```

Newer components may be registry-only until the legacy package distribution is updated.

## Example: Form with Input and Button

```tsx
import { Button } from '@/components/ui/Button';
import { Input } from '@/components/ui/Input';
import { useState } from 'react';

export default function LoginForm() {
  const [email, setEmail] = useState('');

  return (
    <form className="flex flex-col gap-4">
      <Input
        placeholder="Enter your email"
        value={email}
        onChange={(event) => setEmail(event.currentTarget.value)}
      />
      <Button theme="primary" size="lg">
        Sign In
      </Button>
    </form>
  );
}
```

## TypeScript Support

Install paths follow the exported file names. Import prop types from the generated local component file when they are re-exported there:

```tsx
import type { InputProps } from '@/components/ui/Input';
```
