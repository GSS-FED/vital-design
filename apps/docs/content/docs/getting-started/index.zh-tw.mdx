## 概覽

**Vittal Design**（`@fed/vital-design`）是給企業應用使用的 React 元件庫。它提供一套可套用、可調整的無障礙 UI 元件。目前以 registry 發佈的 `src-v2/` 是新元件的主要來源。

> **發佈方式：** 新專案與新元件請使用 registry 的 `src-v2/`。已發佈的 `@fed/vital-design` npm 套件仍可供既有專案相容使用，但它對應的是較舊的 `src/`，不包含只有 registry 才有的 `src-v2` 資產。

## 特性

- **React 19** — 以現代 React 的 hooks 與並行功能建立
- **TypeScript** — 匯出型別，維持完整的型別檢查
- **Tailwind CSS 4** — utility-first 樣式，搭配設計變數
- **Base UI** — `src-v2/` 裡複雜互動使用的無障礙、無樣式 primitive
- **shadcn Registry** — 新元件的主要安裝方式，透過 shadcn CLI

## 設計原則

- **可預期** — 各元件的 props 用法一致
- **可組合** — 元件彼此之間，以及和自訂程式，都能放在一起用
- **無障礙** — 透過 Base UI 提供 ARIA 與鍵盤操作
- **可調主題** — 用 CSS custom properties 調整設計變數
