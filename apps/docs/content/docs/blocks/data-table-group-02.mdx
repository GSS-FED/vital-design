## Composition

This block is built on the following Vittal Design primitives:

- `Avatar`, `Badge`, `Button`, `Card`, `Checkbox`, `DropdownMenu`, `SearchBar`, `Switch`, `Table`, `Tag`, `Toolbar`
- `CaretDownIcon`, `CaretUpIcon`, `ChevronDownIcon`, `EllipsisIcon`
- [`@tanstack/react-table`](https://tanstack.com/table/v8) for state management

## Files

| File                           | Description                                           |
| ------------------------------ | ----------------------------------------------------- |
| `DataTableGroup02.tsx`         | Block entry — selection, sorting, expand, rail layout |
| `action-bar.tsx`               | Search bar, filter buttons, more-actions dropdown     |
| `columns.tsx`                  | `ColumnDef` array with custom cells                   |
| `data-table-column-header.tsx` | Sortable column header with caret sort toggle         |
| `data.ts`                      | Sample emission dataset + tree builder                |
| `pinning.ts`                   | Rail widths, column sizing vars, pinning style helpers |
| `resize-handle.tsx`            | Draggable column resize handle with full-height guide  |
| `table-rail.tsx`               | Sticky chevron/rail cells for grouped rows            |

## Props

| Prop                | Type                      | Default      | Description                                                                                          |
| ------------------- | ------------------------- | ------------ | ---------------------------------------------------------------------------------------------------- |
| `columnResizeMode`  | `'onChange' \| 'onEnd'`   | `'onChange'` | `'onChange'` moves the columns under the pointer. `'onEnd'` holds them and commits on release, with the guide line showing where the edge lands — it does no layout work while dragging, so it stays smooth on wide, heavily pinned tables. |

## Installation

```bash
npx shadcn@latest add @vital-design/data-table-group-02
```

This installs the block under `src/blocks/data-table-group-02/` and pulls every required primitive automatically.
