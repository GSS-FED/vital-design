## 安裝 [#installation]

```bash
npx shadcn@latest add @vital-design/sidebar-cloud-04
```

會安裝 **`app-sidebar.tsx`** 與 `src/public/images/cloud.jpg`（由元件引入）。它依賴 `@vital-design/sidebar`，再加上 avatar、dropdown-menu，以及範例樹裡用到的 icon。在應用裡自己組 `SidebarProvider` 與 `SidebarInset`。

> **素材：** 毛玻璃照片會被引入並一起安裝。範例 logo / avatar 用公開路徑（`/images/vital-logo-text-h.svg`、`/images/vital-logo.svg`、`/images/ray.jpg`），只有文件範例有這些檔；registry 不會安裝。

## 何時使用 [#when-to-use]

- **毛玻璃** Cloud 外觀與 [Flat](/zh-tw/docs/blocks/sidebar/cloud/flat) 相同
- **次要導覽**釘在 `SidebarContent` 底部（`mt-auto`），位於帳號頁尾之上 — Support 與 Privacy Policy，各自有外部連結 icon。底部多留內距，避開收合控制。
- **帳號頁尾**含 avatar dropdown（與 [Inline Submenus](/zh-tw/docs/blocks/sidebar/cloud/inline-submenus) 相同）；收合控制釘在 `bottom-full`
- **沒有子選單** — 主選單保持扁平，與 [Flat](/zh-tw/docs/blocks/sidebar/cloud/flat) 一樣
- 用 `variant="sidebar"` 或 `floating`。不要用 `inset` — 毛玻璃照片塞不進 inset 的內距，也不適合沒有圓角的角落。

## 浮動 [#floating]

傳入 `variant="floating"`，面板會變成四周留空的圓角面板。

## 組合 [#composition]

`CloudSidebar` 是套了外觀的 `Sidebar`（`ComponentProps<typeof Sidebar>`）。範例頁首、導覽、次要導覽與帳號頁尾都組在那個檔案**裡面**，所以 `<CloudSidebar />` 會跟這個預覽一樣。

```tsx
import { CloudSidebar } from '@/blocks/sidebar-cloud-04/app-sidebar';
import {
  SidebarInset,
  SidebarProvider,
  SidebarTrigger,
} from '@/components/ui/Sidebar';

export function Layout({ children }: { children: React.ReactNode }) {
  return (
    <SidebarProvider
      defaultOpen
      style={
        {
          '--sidebar-width': '180px',
          '--sidebar-width-icon': '56px',
        } as React.CSSProperties
      }
    >
      <CloudSidebar collapsible="icon" />
      <SidebarInset className="bg-white">
        <header className="flex h-12 items-center gap-2 border-b px-3 md:hidden">
          <SidebarTrigger />
        </header>
        {children}
      </SidebarInset>
    </SidebarProvider>
  );
}
```

- provider 上建議的寬度：**`--sidebar-width: 180px`**、**`--sidebar-width-icon: 56px`**
- **行動版：** 桌面的圓點會隱藏。把 `SidebarTrigger` 放進 `SidebarInset`（`md:hidden` 的頁首）
- 安裝後改 `data` / `workspaces` 物件。換掉僅供預覽的 `/images/…` 路徑，或在應用裡提供對應的公開檔。

不要產品外觀、只要空白外殼時，自己組 [Sidebar](/zh-tw/docs/components/sidebar)。
