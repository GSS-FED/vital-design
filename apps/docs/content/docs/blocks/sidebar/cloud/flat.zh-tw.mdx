## 安裝 [#installation]

```bash
npx shadcn@latest add @vital-design/sidebar-cloud-01
```

會安裝 **`app-sidebar.tsx`** 與 `src/public/images/cloud.jpg`（由元件引入）。它依賴 `@vital-design/sidebar`，以及範例樹裡用到的 icon。在應用裡自己組 `SidebarProvider` 與 `SidebarInset`。

> **素材：** 毛玻璃照片會被引入並一起安裝。範例 logo 用公開路徑（`/images/vital-logo-text-h.svg`、`/images/vital-logo.svg`），只有 Storybook 與 Fumadocs 的預覽有這些檔；registry 不會安裝。

## 何時使用 [#when-to-use]

- **基本的 Cloud 側邊欄** — 雲朵照片上的毛玻璃；從這裡開始，巢狀導覽再看 [Inline Submenus](/zh-tw/docs/blocks/sidebar/cloud/inline-submenus) 與 [Dropdown Submenus](/zh-tw/docs/blocks/sidebar/cloud/dropdown-submenus)
- **沒有子選單** — 只有扁平導覽（Projects 是單一項目，不是父層）
- 沒有帳號 / 使用者頁尾 — 只留下釘住的圓點收合控制
- 用 `variant="sidebar"` 或 `floating`。不要用 `inset` — 毛玻璃照片塞不進 inset 的內距，也不適合沒有圓角的角落。

## 組合 [#composition]

`CloudSidebar` 是套了外觀的 `Sidebar`（`ComponentProps<typeof Sidebar>`）。範例頁首、導覽與空的頁尾停靠都組在那個檔案**裡面**，所以 `<CloudSidebar />` 會跟這個預覽一樣。

```tsx
import { CloudSidebar } from '@/blocks/sidebar-cloud-01/app-sidebar';
import {
  SidebarInset,
  SidebarProvider,
  SidebarTrigger,
} from '@/components/sidebar/Sidebar';

export function Layout({ children }: { children: React.ReactNode }) {
  return (
    <SidebarProvider
      defaultOpen
      style={
        {
          '--sidebar-width': '180px',
          '--sidebar-width-icon': '56px',
        } as React.CSSProperties
      }
    >
      <CloudSidebar collapsible="icon" />
      <SidebarInset className="bg-white">
        <header className="flex h-12 items-center gap-2 border-b px-3 md:hidden">
          <SidebarTrigger />
        </header>
        {children}
      </SidebarInset>
    </SidebarProvider>
  );
}
```

- provider 上建議的寬度：**`--sidebar-width: 180px`**、**`--sidebar-width-icon: 56px`**
- **行動版：** 桌面的圓點會隱藏。把 `SidebarTrigger` 放進 `SidebarInset`（`md:hidden` 的頁首）
- 安裝後改 `data` / `workspaces` 物件。換掉僅供預覽的 `/images/…` 路徑，或在應用裡提供對應的公開檔。

不要產品外觀、只要空白外殼時，自己組 [Sidebar](/zh-tw/docs/components/sidebar)。
