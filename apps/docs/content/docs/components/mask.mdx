## Usage

```tsx
import Mask from '@/components/ui/Mask';

<Mask height="200px" width="240px">
  <ul>
    {items.map((item) => (
      <li key={item.id}>{item.displayName}</li>
    ))}
  </ul>
</Mask>;
```

## How It Works

`Mask` wraps any scrollable content and:

1. Uses a `ResizeObserver` to detect whether the content overflows the container height
2. Tracks scroll position via the `onScroll` handler
3. Applies a `mask-image` CSS property with a `linear-gradient` fade at the appropriate edge(s):
   - **At top**: fades only the bottom edge
   - **At bottom**: fades only the top edge
   - **In between**: fades both edges
   - **No overflow**: no mask applied

The scrollbar is hidden across all browsers while remaining functional.

<Callout type="info">
  `ListContainer`, Select popups, and Cascader popups include equivalent
  mask logic built in. Use `Mask` directly when you need the fade-scroll
  behaviour on arbitrary content.
</Callout>

## Props

| Prop        | Type            | Default  | Description                                    |
| ----------- | --------------- | -------- | ---------------------------------------------- |
| `children`  | `ReactNode`     | —        | **Required.** Scrollable content               |
| `height`    | `string`        | `'100%'` | Height of the visible viewport (any CSS value) |
| `width`     | `string`        | `'100%'` | Width of the container                         |
| `className` | `string`        | —        | Additional CSS classes on the scroll container |
| `style`     | `CSSProperties` | —        | Inline styles (applied after mask styles)      |
