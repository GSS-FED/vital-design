## 用法 [#usage]

```tsx
import {
  Breadcrumb,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbList,
  BreadcrumbPage,
  BreadcrumbSeparator,
} from '@/components/ui/Breadcrumb';

<Breadcrumb>
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink href="/projects">專案</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbPage>設定</BreadcrumbPage>
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>;
```

目前頁面用 `BreadcrumbPage`。它不是連結，並會設定 `aria-current="page"`。

## 路由連結 [#router-links]

`BreadcrumbLink` 預設渲染 `<a>`。要用路由的連結時，透過 `render` 傳入：

```tsx
import { Link } from 'react-router-dom';

<BreadcrumbLink render={<Link to="/projects" />}>
  專案
</BreadcrumbLink>;
```

## 下拉選單 [#dropdown]

要讓人打開被收起的層級時，把 `BreadcrumbEllipsis` 放進 [`DropdownMenu`](/zh-tw/docs/components/dropdown-menu) 的觸發按鈕。

`BreadcrumbEllipsis` 只做展示，所以觸發按鈕要有名稱，樣式比照麵包屑連結。每個被收起的層級用連結渲染。

## 組成 [#parts]

| Part                  | 元素   | 說明                                                  |
| --------------------- | ------ | ----------------------------------------------------- |
| `Breadcrumb`          | `nav`  | 導覽地標。`aria-label` 預設為 `breadcrumb`            |
| `BreadcrumbList`      | `ol`   | 層級的有序清單。可設 `size`：`'sm'`（預設）或 `'lg'`  |
| `BreadcrumbItem`      | `li`   | 一個層級                                              |
| `BreadcrumbLink`      | `a`    | 連到上層的連結。路由連結用 `render` 傳入              |
| `BreadcrumbPage`      | `span` | 目前頁面，帶 `aria-current="page"`                    |
| `BreadcrumbSeparator` | `li`   | 層級間的分隔。傳 `children` 可替換箭頭                |
| `BreadcrumbEllipsis`  | `span` | 標示隱藏的層級。傳 `children` 可替換省略圖示。放進 `DropdownMenu` 的觸發按鈕可打開這些層級 |

每個 part 也接受其元素的 props。
