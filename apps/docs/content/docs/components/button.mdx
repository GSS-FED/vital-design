## Variants

### Filled (Default)

The default `filled` variant renders a solid background button.

<ComponentPreview>
  <Button variant="filled" theme="primary">Primary</Button>
  <Button variant="filled" theme="default">Default</Button>
  <Button variant="filled" theme="success">Success</Button>
  <Button variant="filled" theme="info">Info</Button>
  <Button variant="filled" theme="warning">Warning</Button>
  <Button variant="filled" theme="alarm">Alarm</Button>
  <Button variant="filled" theme="dangerous">Dangerous</Button>
</ComponentPreview>

```tsx
<Button variant="filled" theme="primary">Primary</Button>
<Button variant="filled" theme="default">Default</Button>
<Button variant="filled" theme="success">Success</Button>
<Button variant="filled" theme="info">Info</Button>
<Button variant="filled" theme="warning">Warning</Button>
<Button variant="filled" theme="alarm">Alarm</Button>
<Button variant="filled" theme="dangerous">Dangerous</Button>
```

### Text

The `text` variant renders a transparent background button. Available for all themes except `dangerous`.

<ComponentPreview>
  <Button variant="text" theme="primary">Primary</Button>
  <Button variant="text" theme="default">Default</Button>
  <Button variant="text" theme="success">Success</Button>
  <Button variant="text" theme="info">Info</Button>
  <Button variant="text" theme="warning">Warning</Button>
  <Button variant="text" theme="alarm">Alarm</Button>
</ComponentPreview>

```tsx
<Button variant="text" theme="primary">Primary</Button>
<Button variant="text" theme="default">Default</Button>
```

## Props

### Button

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `'filled' \| 'text'` | `'filled'` | Visual variant |
| `theme` | `'primary' \| 'default' \| 'success' \| 'info' \| 'warning' \| 'alarm' \| 'dangerous'` | `'primary'` | Color theme (`'dangerous'` only available on `filled`) |
| `size` | `'medium' \| 'large'` | `'medium'` | Button size |
| `icon` | `ReactNode` | — | Icon element to display |
| `iconPlacement` | `'left' \| 'right'` | `'left'` | Icon position relative to label |
| `isLoading` | `boolean` | `false` | Shows spinner and disables interaction |
| `focusableWhenDisabled` | `boolean` | `false` | Keeps the button focusable even when disabled styling is applied |
| `disabled` | `boolean` | `false` | Native disabled attribute |
| `className` | `string` | — | Additional CSS classes |
| `style` | `CSSProperties` | — | Inline styles |
