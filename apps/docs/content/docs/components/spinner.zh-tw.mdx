## 屬性 [#props]

| Prop         | Type                    | Default     | 說明                   |
| ------------ | ----------------------- | ----------- | ----------------------------- |
| `className`  | `string`                | —           | 額外的 CSS class        |
| `aria-label` | `string`                | `'Loading'` | 無障礙標籤              |
| `role`       | `string`                | `'status'`  | 無障礙狀態角色        |
| `...props`   | `ComponentProps<'svg'>` | —           | 原生 `svg` props 與事件 |
