## Input

單行輸入的基礎 primitive。

### 預覽 [#preview]

<ComponentPreview centered={false}>
  <Input placeholder="Enter text..." />
</ComponentPreview>

### 用法 [#usage]

```tsx
import { Input } from '@/components/ui/Input';

<Input
  placeholder="Enter text..."
  value={text}
  onValueChange={setText}
/>;
```

`Input` 建立在 Base UI 的 input primitive 上。受控更新優先用 `onValueChange`；`onChange`、`name`、`type`、`disabled`、`aria-invalid` 這類原生 input props 仍會傳進去。

### Input 屬性 [#input-props]

| Prop             | Type                                      | Default | 說明                        |
| ---------------- | ----------------------------------------- | ------- | --------------------------- |
| `value`          | `string`                                  | —       | 受控值                      |
| `defaultValue`   | `string`                                  | —       | 非受控的初始值              |
| `onValueChange`  | `(value: string) => void`                 | —       | 受控值變更時的回呼          |
| `onChange`       | `ChangeEventHandler<HTMLInputElement>`    | —       | 原生 input 的 change 回呼   |
| `placeholder`    | `string`                                  | —       | 佔位文字                    |
| `disabled`       | `boolean`                                 | `false` | 停用輸入                    |
| `aria-invalid`   | `boolean`                                 | —       | 套用無效框線樣式            |
| `className`      | `string`                                  | —       | 額外的 CSS class            |
| `style`          | `CSSProperties`                           | —       | 行內樣式                    |

## InputGroup

用來自訂前綴、後綴、文字與動作排列的可組合輸入外框。

### 預覽 [#preview-1]

<ComponentPreview centered={false}>
  <InputGroup>
    <InputGroupAddon>
      <InputGroupText>https://</InputGroupText>
    </InputGroupAddon>
    <InputGroupInput placeholder="example.com" />
    <InputGroupAddon align="inline-end">
      <InputGroupButton aria-label="Clear">×</InputGroupButton>
    </InputGroupAddon>
  </InputGroup>
</ComponentPreview>

### 用法 [#usage-1]

```tsx
import {
  InputGroup,
  InputGroupAddon,
  InputGroupButton,
  InputGroupInput,
  InputGroupText,
} from '@/components/ui/InputGroup';

<InputGroup>
  <InputGroupAddon>
    <InputGroupText>https://</InputGroupText>
  </InputGroupAddon>
  <InputGroupInput placeholder="example.com" />
  <InputGroupAddon align="inline-end">
    <InputGroupButton aria-label="Clear">×</InputGroupButton>
  </InputGroupAddon>
</InputGroup>;
```

### InputGroup 部件 [#inputgroup-parts]

| 部件                 | 說明                                           |
| -------------------- | ---------------------------------------------- |
| `InputGroup`         | 帶焦點、停用與無效狀態的視覺外框               |
| `InputGroupInput`    | 單行輸入控制項                                 |
| `InputGroupTextarea` | 多行 textarea 控制項                           |
| `InputGroupAddon`    | 前綴或後綴插槽                                 |
| `InputGroupButton`   | addon 裡的小型動作按鈕                         |
| `InputGroupText`     | addon 裡的靜態文字                             |

## PasswordInput

<a id="password-input"></a>

帶顯示／隱藏切換的密碼輸入。

### 用法 [#usage-2]

```tsx
import { PasswordInput } from '@/components/ui/PasswordInput';

<PasswordInput
  placeholder="Enter password"
  value={password}
  onChange={setPassword}
/>;
```

### PasswordInput 屬性 [#passwordinput-props]

| Prop               | Type                      | Default | 說明                           |
| ------------------ | ------------------------- | ------- | ------------------------------ |
| `value`            | `string`                  | —       | 受控值                         |
| `defaultValue`     | `string`                  | —       | 非受控的初始值                 |
| `onChange`         | `(value: string) => void` | —       | 值變更時的回呼                 |
| `placeholder`      | `string`                  | —       | 佔位文字                       |
| `initiallyVisible` | `boolean`                 | `false` | 一開始就顯示密碼文字           |
| `disabled`         | `boolean`                 | `false` | 停用輸入                       |
| `aria-invalid`     | `boolean`                 | —       | 套用無效框線樣式               |
| `prefix`           | `ReactNode`               | —       | 顯示在左側內部的元素           |
| `onEnter`          | `(value: string) => void` | —       | 按下 Enter 時呼叫              |
| `className`        | `string`                  | —       | 額外的 CSS class               |
| `style`            | `CSSProperties`           | —       | 行內樣式                       |

## Textarea

<a id="textarea"></a>

多行文字欄位。

### 預覽 [#preview-2]

<ComponentPreview centered={false}>
  <Textarea placeholder="Enter description..." rows={4} />
</ComponentPreview>

### 用法 [#usage-3]

```tsx
import { Textarea } from '@/components/ui/Textarea';

<Textarea
  placeholder="Enter description..."
  value={text}
  onChange={(event) => setText(event.currentTarget.value)}
  rows={4}
/>;
```

### Textarea 屬性 [#textarea-props]

| Prop           | Type                                      | Default | 說明                  |
| -------------- | ----------------------------------------- | ------- | --------------------- |
| `value`        | `string`                                  | —       | 受控值                |
| `defaultValue` | `string`                                  | —       | 非受控的初始值        |
| `placeholder`  | `string`                                  | —       | 佔位文字              |
| `disabled`     | `boolean`                                 | `false` | 停用 textarea         |
| `aria-invalid` | `boolean`                                 | —       | 套用錯誤框線樣式      |
| `onChange`     | `ChangeEventHandler<HTMLTextAreaElement>` | —       | 原生值變更回呼        |
| `rows`         | `number`                                  | —       | 原生可見列數          |
| `className`    | `string`                                  | —       | 額外的 CSS class      |
| `style`        | `CSSProperties`                           | —       | 行內樣式              |
