## Usage

```tsx
import {
  Item,
  ItemActions,
  ItemContent,
  ItemDescription,
  ItemMedia,
  ItemTitle,
} from '@/components/ui/Item';

<Item>
  <ItemMedia variant="icon">
    <Icon />
  </ItemMedia>
  <ItemContent>
    <ItemTitle>Title</ItemTitle>
    <ItemDescription>Description</ItemDescription>
  </ItemContent>
  <ItemActions>
    <Button>Action</Button>
  </ItemActions>
</Item>;
```

## Composition

```txt
ItemGroup
`-- Item
    |-- ItemHeader
    |-- ItemMedia
    |-- ItemContent
    |   |-- ItemTitle
    |   `-- ItemDescription
    |-- ItemActions
    `-- ItemFooter
```

Use `Item` for display rows. Use `size="list"` when the row should match picker/list density. Use `Select`, `Combobox`, or `Cascader` for value picking, `DropdownMenu` for action menus, and `Command` for searchable command panels.

## Props

### Item

| Prop        | Type                                  | Default     | Description              |
| ----------- | ------------------------------------- | ----------- | ------------------------ |
| `variant`   | `'default' \| 'outline' \| 'muted'`   | `'default'` | Visual style             |
| `size`      | `'default' \| 'sm' \| 'xs' \| 'list'` | `'default'` | Row density              |
| `render`    | `ReactElement` or render function     | -           | Replace the root element |
| `className` | `string`                              | -           | Additional CSS classes   |

### ItemMedia

| Prop      | Type                             | Default     | Description     |
| --------- | -------------------------------- | ----------- | --------------- |
| `variant` | `'default' \| 'icon' \| 'image'` | `'default'` | Media treatment |

### Parts

`ItemGroup` renders `role="list"` by default. `ItemDescription` is clamped to two lines by default. `ItemSeparator` uses `Separator` props. `ItemContent`, `ItemTitle`, `ItemDescription`, `ItemActions`, `ItemHeader`, and `ItemFooter` accept native element props.
