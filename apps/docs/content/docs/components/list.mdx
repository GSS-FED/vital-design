## Overflow with Mask

When a `height` is set on `ListContainer`, items that overflow are scrollable. A fade mask is automatically applied at the top/bottom edges.

## List Components

<a id="list-components"></a>

`list-components` is the registry key for the reusable primitives documented on this page: `ListContainer` and `ListItem`.

## Usage

```tsx
import {
  ListContainer,
  type Option,
} from '@/components/ui/ListContainer';
import { ListItem } from '@/components/ui/ListItem';
import { useState } from 'react';

const items: Option[] = [
  { id: 1, displayName: 'Apple' },
  { id: 2, displayName: 'Banana' },
  { id: 3, displayName: 'Cherry' },
];

function MyList() {
  const [selected, setSelected] = useState<
    string | number | undefined
  >(undefined);

  return (
    <ListContainer items={items} height={120}>
      {items.map((item) => (
        <ListItem
          key={item.id}
          $selected={selected === item.id}
          onClick={() => setSelected(item.id)}
        >
          {item.displayName}
        </ListItem>
      ))}
    </ListContainer>
  );
}
```

<Callout type="info">
  For field pickers, use Select, Combobox, or Cascader. For custom
  list panels, compose these primitives directly and own the loading
  or virtualization logic in your app.
</Callout>

## ListContainer Props

| Prop        | Type            | Default  | Description                                                         |
| ----------- | --------------- | -------- | ------------------------------------------------------------------- |
| `items`     | `Option[]`      | —        | **Required.** Used to determine whether overflow masking is needed  |
| `height`    | `number`        | —        | Fixed height (px) for the scrollable area; enables overflow masking |
| `width`     | `string`        | `'100%'` | Width of the container                                              |
| `children`  | `ReactNode`     | —        | `ListItem` elements to render                                       |
| `className` | `string`        | —        | Additional CSS classes                                              |
| `style`     | `CSSProperties` | —        | Inline styles                                                       |

## ListItem Props

| Prop        | Type         | Default | Description                                   |
| ----------- | ------------ | ------- | --------------------------------------------- |
| `children`  | `ReactNode`  | —       | Item label content                            |
| `$selected` | `boolean`    | —       | Applies the selected (primary) colour         |
| `$disabled` | `boolean`    | —       | Mutes colour and disables hover/active states |
| `onClick`   | `() => void` | —       | Called when the item is clicked               |
| `className` | `string`     | —       | Additional CSS classes                        |

## Option Type

```ts
type Option = {
  id: string | number;
  displayName: string;
  disabled?: boolean;
};
```
