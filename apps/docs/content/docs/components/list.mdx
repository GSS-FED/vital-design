## Overflow with Mask

When a `height` is set on `ListContainer`, items that overflow are scrollable. A fade mask is automatically applied at the top/bottom edges.

## List Components

<a id="list-components"></a>

`list-components` is the registry key for the reusable primitives documented on this page: `ListContainer`, `ListItem`, and `InfiniteList`.

## Usage

```tsx
import { useState } from 'react';
import ListContainer, { type Option } from '@/components/ui/ListContainer';
import { ListItem } from '@/components/ui/ListItem';

const items: Option[] = [
  { id: 1, displayName: 'Apple' },
  { id: 2, displayName: 'Banana' },
  { id: 3, displayName: 'Cherry' },
];

function MyList() {
  const [selected, setSelected] = useState<string | number | undefined>(undefined);

  return (
    <ListContainer items={items} height={120}>
      {items.map((item) => (
        <ListItem
          key={item.id}
          $selected={selected === item.id}
          onClick={() => setSelected(item.id)}
        >
          {item.displayName}
        </ListItem>
      ))}
    </ListContainer>
  );
}
```

## Infinite Scroll

For very large or server-paginated lists, use `InfiniteList`. It virtualises rows with `react-window` and loads pages on demand via `react-window-infinite-loader`.

```tsx
import InfiniteList from '@/components/ui/InfiniteList';

<InfiniteList
  items={items}
  hasNextPage={hasNextPage}
  loadNextPage={fetchNextPage}
  listHeight={240}
  listItem={(item) => (
    <ListItem onClick={() => setSelected(item.id)}>
      {item.displayName}
    </ListItem>
  )}
/>
```

## ListContainer Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `items` | `Option[]` | — | **Required.** Used to determine whether overflow masking is needed |
| `height` | `number` | — | Fixed height (px) for the scrollable area; enables overflow masking |
| `width` | `string` | `'100%'` | Width of the container |
| `children` | `ReactNode` | — | `ListItem` elements to render |
| `className` | `string` | — | Additional CSS classes |
| `style` | `CSSProperties` | — | Inline styles |

## ListItem Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `ReactNode` | — | Item label content |
| `$selected` | `boolean` | — | Applies the selected (primary) colour |
| `$disabled` | `boolean` | — | Mutes colour and disables hover/active states |
| `onClick` | `() => void` | — | Called when the item is clicked |
| `className` | `string` | — | Additional CSS classes |

## InfiniteList Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `items` | `T[]` | — | **Required.** Array of loaded items |
| `hasNextPage` | `boolean` | — | **Required.** Whether more pages exist |
| `loadNextPage` | `() => void \| Promise<void>` | — | **Required.** Callback to fetch the next page |
| `listHeight` | `number` | — | **Required.** Pixel height of the virtualised list viewport |
| `listItem` | `(item: T) => JSX.Element` | — | **Required.** Render function for each item row |
| `isNextPageLoading` | `boolean` | — | Shows a spinner row while loading |
| `width` | `string` | — | Width passed to the outer wrapper |
| `className` | `string` | — | Additional CSS classes |
| `style` | `CSSProperties` | — | Inline styles |

## Option Type

```ts
type Option = {
  id: string | number;
  displayName: string;
  disabled?: boolean;
};
```
