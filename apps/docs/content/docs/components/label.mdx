## Props

| Prop        | Type                      | Default | Description                     |
| ----------- | ------------------------- | ------- | ------------------------------- |
| `htmlFor`   | `string`                  | —       | Associated control id           |
| `className` | `string`                  | —       | Additional CSS classes          |
| `style`     | `CSSProperties`           | —       | Inline styles                   |
| `...props`  | `ComponentProps<'label'>` | —       | Native `label` props and events |
