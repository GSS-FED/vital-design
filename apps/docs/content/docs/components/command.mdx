## Usage

```tsx
import Command from '@/components/ui/Command';
import { useState } from 'react';

function Example() {
  const [search, setSearch] = useState('');

  return (
    <Command label="Quick actions" className="h-[300px] w-[240px]">
      <Command.Input
        placeholder="Search actions"
        value={search}
        onValueChange={setSearch}
      />
      <Command.List className="flex-1">
        <Command.Empty>No results</Command.Empty>
        <Command.Group heading="Suggestions">
          <Command.Item value="Profile">Profile</Command.Item>
          <Command.Item value="Billing">Billing</Command.Item>
        </Command.Group>
      </Command.List>
    </Command>
  );
}
```

## Action List Preset

The old `ActionList` shape is now just a `Command` recipe. The default look is the same idea: rounded search input, padded rows, and a simple selected state.

## Infinite Data

`Command` owns the shell. Your app owns loading, filtering, pagination, and virtualization.

<CommandInfinitePreview />

For virtualized data, use `shouldFilter={false}` and render only the visible `Command.Item`s from your preferred list library.

## Parts

### Command

Root container for the panel state and keyboard interaction.

### Command.Input

Search input with the default Vital shell. Use `containerClassName` when you want a preset-like layout without creating another component.

### Command.List

Scrollable list viewport with built-in mask behaviour.

### Command.Item

Selectable row. Use `value` for predictable filtering and keyboard selection.

### Command.Group

Optional visual grouping with headings.

### Command.Empty

Empty state shown when no items match.

### Command.Loading

Loading row for async and infinite data.

### Command.BackButton

Back navigation affordance for nested-page flows.
