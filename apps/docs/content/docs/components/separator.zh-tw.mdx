## 屬性 [#props]

| Prop          | Type                          | Default        | 說明                              |
| ------------- | ----------------------------- | -------------- | --------------------------------- |
| `orientation` | `'horizontal' \| 'vertical'`  | `'horizontal'` | 分隔線方向                        |
| `className`   | `string`                      | —              | 額外的 CSS class                  |
| `style`       | `CSSProperties`               | —              | 行內樣式                          |
| `...props`    | `ComponentProps<typeof Base>` | —              | Base UI separator 的 props 與事件 |
