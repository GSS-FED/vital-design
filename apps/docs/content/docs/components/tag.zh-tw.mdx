## 用法 [#usage]

```tsx
import { Tag } from '@/components/ui/Tag';

<Tag color="blue" colorVariant="tint">Design</Tag>
<Tag color="green" colorVariant="solid">Active</Tag>
```

## 可移除 [#removable]

Tag 可以用 `removable` 與 `onRemove` 加上移除按鈕：

<TagRemovablePreview />

```tsx
<Tag
  color="blue"
  colorVariant="tint"
  removable
  onRemove={() => removeTag(id)}
>
  React
</Tag>
```

## 屬性 [#props]

| Prop           | Type                                                                                                                            | Default     | 說明                              |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------- | ----------- | ---------------------------------------- |
| `children`     | `ReactNode`                                                                                                                     | —           | **必填。** Tag 內容                |
| `color`        | `'default' \| 'teal' \| 'olive' \| 'brown' \| 'rose' \| 'indigo' \| 'blue' \| 'green' \| 'gold' \| 'red' \| 'purple' \| 'navy'` | `'default'` | Tag 顏色                                |
| `colorVariant` | `'solid' \| 'tint'`                                                                                                             | `'tint'`    | 色彩樣式變體                      |
| `icon`         | `ReactNode`                                                                                                                     | —           | 渲染在標籤前的圖示           |
| `removable`    | `boolean`                                                                                                                       | `false`     | 顯示移除（×）按鈕                |
| `selected`     | `boolean`                                                                                                                       | `false`     | 套用選取樣式                 |
| `onClick`      | `() => void`                                                                                                                    | —           | 點擊處理函式                            |
| `onRemove`     | `() => void`                                                                                                                    | —           | 點擊移除按鈕時呼叫 |
| `className`    | `string`                                                                                                                        | —           | 額外的 CSS class                   |
| `style`        | `CSSProperties`                                                                                                                 | —           | 行內樣式                            |
