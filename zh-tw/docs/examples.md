# 範例畫面

> 只用 Vital Design 元件與 blocks 組成的完整畫面，看各元件怎麼搭在一起。

## 任務

專案工作區：Cloud sidebar block；頁首有 Breadcrumb、Search Bar、Tooltip、Badge 與帳號 Dropdown Menu；統計 Card 搭配 Tag 與 Progress；再加上 Tabs 與 Data Table block。

## 設定

帳號設定表單：Card、Field、Input、Select、Textarea、Switch、Radio Group 與 Separator。按 **儲存** 會跳出 Toast，按 **刪除帳號** 會開 Dialog。
