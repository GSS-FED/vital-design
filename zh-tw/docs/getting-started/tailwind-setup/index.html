Tailwind CSS 設定

讓 Tailwind CSS 4 使用 Vittal Design 元件與設計變數。

概覽

這一頁適用於 從 registry 安裝的 Vittal Design 元件。透過相容 shadcn 的 registry 安裝 src-v2/ 元件時，CLI 會把元件複製進應用，並把 Vittal Design 的主題變數與少量基礎 CSS 寫進 components.json 指定的 CSS 檔。

如果既有專案仍使用已發佈的 @fed/vital-design npm 套件，維持原本的 src/ 整合即可。npm 套件不會把只有 registry 才有的 src-v2 樣式表當成公開 import。

如果 components.json 指到 Tailwind 自動掃描範圍之外的目錄，再加一條對應本地元件路徑的 @source。

用 data-slot 隔離樣式

Vittal Design 元件會在可上樣式的 DOM 部分放上穩定的 data-slot。用這些鉤子把 Tailwind utilities 與自訂 CSS 限縮在 VD 元件上，避免樣式漏到應用自己的元素，也避免反過來被蓋掉。

這跟 shadcn 的 data-slot 慣例 一致：每個 DOM 表面 都有可預期的選擇器。

命名

部分data-slot 的值元素範例
Root{component}data-slot="button"
子部分{component}-{part}data-slot="select-trigger"

層級規則例子

@base-ui/react 與 cmdk 沒有附 data-slot。直接再匯出的元件在 Vittal Design 包上一層之前不會有 slot。不要預期 Select 的 root 或 ToastPortal 有 slot。請改以子部分為範圍，例如 select-trigger 或 toast-content。

第三層豁免（刻意沒有 slot）：select、dialog、dropdown-menu、popover、tooltip、toast、autocomplete 上的 Provider、只有狀態的 Root、空的 Portal。AutocompleteValue / ComboboxValue 也豁免，它們不渲染 DOM（只有文字或 children）。
