Tag

用來分類、表示狀態與篩選的標籤。支援 12 種顏色、兩種變體，以及可選的移除動作。

可點擊

傳入 onClick 時，標籤文字會渲染成按鈕，滑過時有覆蓋效果。

可點擊又可移除

onClick 與 onRemove 可以同時使用。點移除按鈕不會觸發 onClick。

已選取

selected 會畫出主色外框。搭配 onClick 時也會設定 aria-pressed，讓 tag 當成切換按鈕使用。
