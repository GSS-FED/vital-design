Command

建立在 cmdk 上、可組合的命令面板 primitive，含輸入、清單、項目、群組與快捷鍵。

用法

Command 是 cmdk 的薄樣式包裝。用來做命令面板、自訂的可搜尋彈出層、分頁的階層選擇器，或任何以鍵盤篩選的清單。

cmdk 會依 CommandInput 輸入的文字，比對每個 CommandItem 的文字內容來篩選。要自己處理篩選時，在 Command 上傳 shouldFilter={false}。

命令面板／自訂的可搜尋清單Command

Command 不含 popover 或觸發器。需要浮動面板時，搭配 Popover（或自己的表面）。Tree Select 區塊是用 Command 與 Popover 組出的分頁樹狀選擇器。

狀態

項目載入中時，在清單裡放 CommandLoading。沒有項目符合搜尋時會顯示 CommandEmpty。

匯出

匯出說明
CommandRoot 容器；接受 cmdk props（shouldFilter、filter、label 等）
CommandInput搜尋輸入列，前方有搜尋圖示
CommandList可捲動的清單 primitive
CommandEmpty沒有項目符合時的空狀態
CommandGroup分組項目，可選 heading
CommandSeparator群組之間的水平分隔線
CommandItem可選取的列；觸發 onSelect
CommandShortcut項目內靠右的鍵盤提示
CommandLoading載入列，預設帶 spinner
CommandHeader輸入框上方的 header slot（用於返回按鈕）
CommandBackButton分頁流程用的返回按鈕樣式
