Calendar

建立在 react-day-picker 上的日期選擇月曆。支援單選、範圍與多選，並可完整覆寫 classNames 與 components。

預覽

SuMoTuWeThFrSa

用法

用 selected 與 onSelect 控制選取，值的形狀依 mode 而定。月曆預設開在本月；要開在別的月份，傳入 defaultMonth。

停用日期

年月下拉標題

January 2026
SuMoTuWeThFrSa

傳入 captionLayout="dropdown"（或 "dropdown-months" / "dropdown-years"），並用 startMonth / endMonth 限制可瀏覽的範圍。月份選擇器是 3 欄網格，年份選擇器是可捲動清單（Vittal 的 Popover，不是原生 select）；年份選擇器開啟時會把目前年份置中。要自訂時覆寫 components={{ MonthsDropdown, YearsDropdown }}。要翻譯下拉標籤，傳入 locale（見 在地化）；要改它們的格式，覆寫 formatMonthDropdown。

在地化

Calendar 沒有預設 formatter。它保持與語系無關，翻譯交給呼叫端。有兩個各自獨立的層：

  1. locale — 哪一種語言。 從 react-day-picker/locale 引入 locale，傳給 locale。它決定星期標題、caption 與下拉標籤的語言和順序。
  2. formatters — 怎麼呈現。 只有想要不同於該語系預設的格式時，才覆寫 formatters。它們是直接轉給 react-day-picker 的。

語系

2026年1月
一二三四五六日

只靠 locale 就會得到 CJK 星期標籤（一 二 三 …）、從星期一開始的一週，以及下拉裡的中文月份名稱（一月），不必自己寫 formatter。

語系與 formatter

在 locale 之上再加 formatter，可以改寫已經在地化的值。每個 formatter 收到的 dateLib 帶有目前的 locale，所以要透過它格式化，才會維持在地化。這裡月份下拉顯示短月份（1月、2月 …），而不是語系預設的全名（一月）：

導覽

標題列預設有跳年箭頭（« »），夾在單月步進（‹ ›）兩側；跳年會遵守 startMonth / endMonth。只要單月導覽時（例如放在日期時間選擇器裡），透過 components 覆寫 Nav slot。

Props

Calendar 延伸自 react-day-picker 的 DayPickerProps。最常用的 props：

PropTypeDefault說明
mode'single' | 'range' | 'multiple'—選取模式
selectedDate | DateRange | Date[]—選取的日期；形狀依 mode 而定
onSelect(value) => void—選取變更時呼叫
numberOfMonthsnumber1並排顯示幾個月
showOutsideDaysbooleantrue顯示相鄰月份的前後日期
captionLayout'label' | 'dropdown' | 'dropdown-months' | 'dropdown-years''label'月／年標題的樣式
startMonthDate—使用者能前往的最早月份
endMonthDate—使用者能前往的最晚月份
disabledMatcher | Matcher[]—不能選取的日期（見 react-day-picker 文件）
formattersPartial<Formatters>—覆寫標籤 formatter（星期、caption 等）
classNamesPartial<ClassNames>—依部分覆寫 class name
componentsPartial<CustomComponents>—覆寫內建元件（例如 Nav、DayButton）
classNamestring—root 上的額外 class
