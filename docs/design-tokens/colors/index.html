Design Tokens

Colors

Vital Design color system — primitive palettes, semantic aliases, and named component tokens.

Overview

Vital Design follows the shadcn/ui naming convention for its semantic layer. Colors are defined under tokens/ (Style Dictionary), built into src-v2/styles/tokens/generated.css as CSS custom properties on :root, and exposed to Tailwind via @theme inline (--color-*).

  • Primitive scales (--primary-50…900, --grayscale-100…900, --grayscale-opacity-100…900, --success-100…900, etc.) — internal foundation. Reach for these when you need a specific shade for charts, illustrations, or fine-grained tinting. Tailwind utility: bg-primary-500, text-grayscale-700, etc.
  • Semantic tokens (--background, --primary, --card, --destructive, …) — the public API. These describe intent and pair with -foreground siblings for legible content on the surface. Tailwind utility: bg-primary text-primary-foreground.
  • Component tokens (--avatar-*-fg, --tag-*-solid) — closed palettes used by specific components.
