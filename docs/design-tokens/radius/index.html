Usage Guidance

TokenRecommended usage
--radius-noneSquare corners — utility surfaces, inline edge-to-edge groups
--radius-smSmall inputs, compact buttons, tags
--radius-mdDefault form controls, table cells, cards
--radius-lgMedium buttons, alert containers
--radius-xlCards, dialogs, large buttons
--radius-fullPill / circular shapes — chips, avatars, status dots

Combining With Sizes

Pair radius tokens with size utilities to get consistent component shapes. Vital's button, input, and chip components all key off the same scale internally.
