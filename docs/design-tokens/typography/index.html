Typography

Font family, type scale, weights, and text style conventions used across Vital Design.

Font Family

Vital Design ships a single sans-serif stack via the --font-sans CSS variable, registered as the Tailwind font-sans token.

The stack prioritises:

  1. Roboto — Latin / UI text
  2. Noto Sans TC / PingFang TC / Microsoft JhengHei — Traditional Chinese fallbacks

Type Scale

Vital Design relies on Tailwind's default type scale — there are no project-specific font-size tokens. Reach for these utilities for content typography.

Heading 1 — text-4xl

Build elegant interfaces faster.

Heading 2 — text-3xl

Composable, accessible primitives.

Heading 3 — text-2xl

Section heading

Heading 4 — text-xl

Subsection heading

Lead — text-lg

A larger paragraph used to introduce a section or summarize the page.

Paragraph — text-base

The default body size. Use this for paragraph copy in long-form content.

Small — text-sm

Form labels, table cells, button text, and other UI copy default to this size.

Caption — text-xs

Helper text, captions, metadata, and small labels.

See the Tailwind type scale docs for the full range (text-xs through text-9xl).

Text Color

Vital Design's grayscale palette uses progressive transparency, so the same text token reads consistently on light and tinted backgrounds. Use the semantic --text-* tokens for intent, or pick a grayscale step directly when you need exact contrast control.
