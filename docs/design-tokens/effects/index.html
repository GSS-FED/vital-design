Design Tokens

Effects

Elevation shadows, focus rings, button shadows, and gradient tokens.

Elevation

Four elevation shadows for layering content. accent is the softest; top-level is reserved for modal-class surfaces.

--shadow-accent
shadow-accent
--shadow-base
shadow-base
--shadow-emphasis

Focus Rings

Outer rings rendered as box-shadow so they don't shift layout. Match the colour to the control's intent:

  • --shadow-focus-* — solid 2px ring tinted with the matching 200 step
  • --shadow-focus-ring-* — softer translucent ring used for inline-edited controls (inputs, search bars)
--shadow-focus-primary
--shadow-focus-success
--shadow-focus-info
--shadow-focus-warning
--shadow-focus-destructive
--shadow-focus-ring-primary
--shadow-focus-ring-destructive

Button Shadows

Pre-baked drop shadows that match the five button themes. The -active variants are the pressed-state counterparts.

--shadow-button-primary-active
--shadow-button-success
--shadow-button-success-active
--shadow-button-info
--shadow-button-info-active
--shadow-button-warning

--shadow-button-destructive-active

Gradients

A single gradient family used for primary buttons and accent surfaces.

--gradient-primary
--gradient-primary-button

--gradient-primary-button is an alias of --gradient-primary provided for forward compatibility — both currently resolve to the same linear-gradient(45deg, #33CFFF 0%, #0E86FE 100%).

Border Radius

Corner radius tokens shared by inputs, buttons, cards, and dialogs.
