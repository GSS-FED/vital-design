Tabs

Switch between related panels with underline or pill tab styles.

Preview

Overview content

Usage

The active underline renders per trigger and grows from width 0, so no extra element is needed.

Bordered

Use bordered on TabsList when the underline tabs need a rail border.

Sliding indicator

By default the active underline grows from width 0 under each tab. Render TabsIndicator inside TabsList to opt into a single bar that slides between tabs instead — adding it disables the per-tab grow highlight.
