Pass captionLayout="dropdown" (or "dropdown-months" / "dropdown-years") and bound the navigable range with startMonth / endMonth. The month picker is a 3-column grid and the year picker a scrollable list (Vital Popovers, not native selects); the year picker centers the current year on open. Override components={{ MonthsDropdown, YearsDropdown }} to customize. To translate the dropdown labels, pass a locale (see Localization); to change their format, override formatMonthDropdown.

Localization

Calendar ships no default formatters — it stays locale-neutral and leaves translation to the caller. There are two independent layers:

  1. locale — which language. Import a locale from react-day-picker/locale and pass it as locale. It drives the weekday header, caption, and dropdown labels in the right language and order.
  2. formatters — how it renders. Override formatters only when you want a different format than the locale's default. They are a pure react-day-picker pass-through.

The locale alone gives CJK weekday labels (日 一 二 …) and a YYYY年M月 caption — no hand-written formatters.

Locale + formatter

Layer a formatter on top of the locale to reshape an already-localized value. The dateLib argument passed to each formatter carries the active locale, so format through it to stay localized. Here the month dropdown shows the short month (1月, 2月 …) instead of the locale default full name (一月):
