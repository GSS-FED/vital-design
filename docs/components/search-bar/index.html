SearchBar

A search input with an icon. Supports instant onChange and explicit onSearch (Enter / icon click).

Preview

Usage

onChange fires on every keystroke with the current value. onSearch fires when the user presses Enter, or clicks the search icon when isSearchIconClickable is set. The example above shows the last submitted query.

States

Use disabled to disable the search bar. Long values truncate with an ellipsis.

Props

PropTypeDefaultDescription

defaultValuestring—Uncontrolled initial value
placeholderstring—Placeholder text
onChange(value: string) => void—Called on every keystroke
onSearch(value: string) => void—Called when Enter is pressed or icon is clicked
isSearchIconClickablebooleanfalseMakes the search icon trigger onSearch on click
disabledbooleanfalseDisables the input
widthstring—Custom width (e.g., '300px')
classNamestring—Classes for the InputGroup shell
styleCSSProperties—Inline styles for the InputGroup shell

Every other <input> prop (id, name, aria-label, autoFocus, inputMode, enterKeyHint, onBlur, …) is forwarded to the inner input, and ref points at that input.

Controlled vs uncontrolled

Pass value when something outside the component owns the query — a URL search param, a "clear all filters" button, or a suggestion chip that fills the field. Pass defaultValue instead when the input itself is the only source of truth and onChange just feeds a request. Setting both makes defaultValue inert.
