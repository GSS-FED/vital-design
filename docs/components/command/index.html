Command

A composable command palette primitive built on cmdk, with input, list, items, groups, and shortcut display.

Usage

Command is a thin styled wrapper around cmdk. Use it to build command palettes, custom searchable popups, paged hierarchical pickers, or any list UI with keyboard-driven filtering.

Filtering is handled by cmdk based on the typed CommandInput value matching each CommandItem's text content. Pass shouldFilter={false} on Command to opt out and run your own filter logic.

When to Use

NeedComponent
Flat value pickerSelect
Searchable value picker (input + popup)Combobox
Hierarchical path pickerCommand + Popover
Action menuDropdownMenu
Command palette / custom searchable listCommand

Command does not include a popover or trigger — pair it with Popover (or your own surface) when you need a floating panel. The Storybook HierarchicalPicker story shows a paged tree picker built from Command and Popover.
