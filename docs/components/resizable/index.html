Resizable

Accessible resizable panels backed by react-resizable-panels.

Usage

Resizable wraps react-resizable-panels. Compose ResizablePanelGroup with ResizablePanel children separated by ResizableHandle. Nest groups to build mixed horizontal/vertical layouts.

Vertical

Header

Content

With Handle

Pass withHandle to ResizableHandle to render a visible drag indicator. Use a minSize on a panel to prevent it from collapsing.

ResizablePanelGroup Props

Accepts every prop from react-resizable-panels's PanelGroup.

PropTypeDefaultDescription
orientation'horizontal' | 'vertical''horizontal'Layout direction

ResizablePanel Props

Accepts every prop from react-resizable-panels's Panel.

PropTypeDefaultDescription
defaultSizenumber | string—Initial size as percentage
minSizenumber | string—Minimum size before collapse
maxSizenumber | string—Maximum size
collapsiblebooleanfalseAllow collapsing past collapsedSize
idstring—Required if autoSaveId is set on group
