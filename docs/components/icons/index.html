Usage

Import each icon from its dedicated file. Barrel imports (@/icons) are intentionally not allowed in component source so that registry consumers only pull in the icons they actually use.

Available icons:

Sizes

Control the icon size with Tailwind's size-* utility — each icon SVG fills the container set by width/height.

Colors

Icons inherit currentColor, so any Tailwind text color utility applies.

SpinnerIcon

SpinnerIcon renders the static glyph. Add Tailwind's animate-spin utility when you need rotation, or use the Spinner component for loading status UI.

Props

All icons accept standard SVG props. Size and color should normally be controlled with Tailwind classes.
