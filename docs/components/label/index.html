Label

Accessible label text associated with a form control.

Preview

Usage

Pair htmlFor with the control's id so clicking the label focuses the control. For a label with a description or error message, use Field.

Required

required adds the Vittal Design required dot to the label. Keep the actual required state on the control too.

With Disabled Input

Disabling the input doesn't change the label. To dim the label with the control, use Field with data-disabled.
