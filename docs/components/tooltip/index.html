Tooltip

A short, transient hint anchored to a trigger element with arrow and side controls.

Preview

Usage

Tooltip is built on Base UI's Tooltip. Wrap a region of triggers in TooltipProvider to share open and close delays, then compose Tooltip, TooltipTrigger, and TooltipContent. The default offset matches the design (8 px from the anchor).

With Icon

The content is a flex row, so add an icon next to the message to mark warnings or status hints.

Side

side selects which edge of the trigger the tooltip anchors to. Base UI will flip the side automatically to avoid clipping.

Align

align shifts the tooltip along the chosen side.

Long Content

The popup wraps at the configured 400px max width.

Without Arrow

Pass arrow={false} to drop the pointer when the tooltip is anchored to custom layouts that don't need a beak.
