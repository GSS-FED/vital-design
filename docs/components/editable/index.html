Editable

Inline editable text field with display, input, and textarea parts.

Preview

Usage

Editable is a compound component for inline text editing. The display surface looks like static text; clicking it swaps in an Input (or Textarea) focused with the caret at the end. Pressing Enter (or blurring) commits the value through onCommit; Escape discards the staged edit.

Textarea Variant

Swap EditableInput for EditableTextarea when the field should accept multi-line content. Enter inserts a newline; click outside to commit.

Controlled

Provide value together with onCommit to drive the field from outside. The component still manages its own staged edit buffer internally, so the parent only receives the committed value.

Current value: Alice

States

When the value is empty, EditableDisplay renders the placeholder text with a visible border so the affordance stays visible. Pass disabled to block editing entirely, or readOnly to keep the display interactive-looking but ignore enter-edit clicks.
