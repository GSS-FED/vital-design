NumberInput

A numeric input with stepper buttons, locale-aware formatting, and clamped step interactions.

Preview

Usage

NumberInput is built on Base UI's Number Field. The root manages the numeric value, clamping, formatting, and the disabled state of every part. Compose NumberInputGroup, NumberInputControl, and NumberInputSteppers to render the field.

Min, Max, And Step

min and max clamp values from the steppers, keyboard, and wheel. step controls the increment per arrow press; smallStep and largeStep are used when the meta or shift key is held.

States

Disable every part with disabled on NumberInput, or keep the value focusable but unchangeable with readOnly. Set aria-invalid on NumberInputControl to apply the error border style.

Currency Formatting

Pass Intl.NumberFormatOptions via format to render the value in any locale-aware shape.

Controlled

Use value and onValueChange to drive the field from state. The callback emits null when the input is empty. Wrap a label in NumberInputScrubArea to let users drag it to change the value.

NumberInput Parts

PartDescription
NumberInputGroupVisual shell with focus, disabled, and aria-invalid states
NumberInputControlThe native input that displays and parses the formatted value
NumberInputSteppersConvenience layout that stacks the increment and decrement buttons on the right
NumberInputIncrementStepper button that adds step to the value
NumberInputDecrementStepper button that subtracts step from the value
NumberInputScrubAreaOptional region that scrubs the value with pointer drags
NumberInputScrubAreaCursorCursor element rendered while scrubbing

All parts forward refs to their underlying DOM elements and accept Base UI className state functions.
