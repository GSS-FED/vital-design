Changelog

User-facing changes to the Vital Design registry, components, and docs.

This page tracks the registry-backed design system on vittal.design: components, blocks, tokens, and documentation. It does not track the legacy @fed/vital-design npm package.

That package is built from src/ and stays available for existing apps. New work ships through the registry. If you still import from the package, see the Migration Guide.

Newest entries are at the top. Headings use the month the change shipped. We only record changes that affect how you install or use the registry — new components, breaking usage, tokens, and install steps.

October 2026 — React 19

The registry and the docs site are developed and tested on React 19. New projects should use React 19. See Installation.

October 2026 — Link button

Components

  • Button: added LinkButton, a link styled as a button. It shares Button's variants, themes, and sizes, renders <a> (or a router link via render), and keeps link semantics. Use it instead of <Button nativeButton={false} render={<a />}>, which reports links as buttons. See Button → Link.

October 2026 — Table stripes and column resize

Table

Table can stripe body rows. striped paints even rows. striped="odd" paints the other rows. Set --table-stripe and --table-row-hover on the table to change the colors.

Reinstall the table to pick this up:

pnpm dlx shadcn@latest add @vital-design/table

Breaking: hover, expanded, and selected row backgrounds no longer use bg-grayscale-opacity-100. They read --table-row-hover. With striped left off, that variable still falls back to --grayscale-opacity-100, so the default look stays the same.

  • hover:bg-grayscale-opacity-100 → hover:bg-[var(--table-row-hover,var(--grayscale-opacity-100))]
  • data-[state=selected]:bg-grayscale-opacity-100 → data-[state=selected]:bg-[var(--table-row-hover,var(--grayscale-opacity-100))]

TableHead is now position: relative. An absolutely positioned child lines up with the header cell. If one of yours was lined up with an ancestor outside the cell, point it at the cell instead.

Icons

Caret up and caret down are new registry icons. See Icons.

pnpm dlx shadcn@latest add @vital-design/icon-caret-up
pnpm dlx shadcn@latest add @vital-design/icon-caret-down

Data tables

Data Table group 01 and group 02 can resize columns. Drag the header edge. columnResizeMode defaults to onChange. Use onEnd on a wide table with many pinned columns so the columns stay put until you release.

Reinstall both blocks. Group 02 also swaps its sort icon from chevron up to the caret pair, and drops @vital-design/icon-chevron-up. @vital-design/icon-chevron-down stays for the row rail. The sort label truncates so the caret stays visible when a column gets narrow.

pnpm dlx shadcn@latest add @vital-design/data-table-group-01
pnpm dlx shadcn@latest add @vital-design/data-table-group-02

September 2026 — Registry on vittal.design

The documentation site and the shadcn-compatible registry now publish together at vittal.design. This entry is a snapshot of what is available today. Later entries will list only what changed.

Install

Add the registry, then install items with the shadcn CLI. See Installation.

pnpm dlx shadcn@latest add @vital-design/button

Registry URL: https://vittal.design/r/{name}.json

Components

Foundation: Alert, Avatar, Badge, Button, Button Group, Chip, Icons, Item, Label, Separator, Skeleton, Spinner, Split Button, Tag

Inputs: Checkbox, Editable, Field, Input, Number Input, Radio Group, Search Bar, Slider, Switch, Textarea

Pickers and menus: Autocomplete, Calendar, Combobox, Command, Dropdown Menu, Popover, Select, Time Picker

Overlays and feedback: Dialog, Sheet, Toast, Tooltip

Layout and data: Card, Collapsible, Progress, Resizable, Scroll Area, Sidebar, Table, Tabs, Toolbar

Blocks

  • Cloud Sidebar: flat, inline submenus, collapsible submenus, dropdown submenus, secondary nav, header actions
  • Data Table: group 01, group 02, group 04

Tokens

Colors, typography, radius, and effects ship as CSS variables with the registry theme.

Platform

  • Components use Base UI primitives and Tailwind CSS 4
  • Style isolation follows the data-slot convention in Tailwind CSS Setup
  • Agent index: llms.txt

Registry

Install Vittal Design components individually using the shadcn CLI.
