Composition

This block is built on the following Vital Design primitives:

  • Avatar, Button, Card, Checkbox, DropdownMenu, Progress, SearchBar, Table, Tag, Toolbar
  • ChevronDownIcon, EllipsisIcon
  • @tanstack/react-table for state management

Files

FileDescription
DataTableGroup01.tsxBlock entry — wires columns, state, expand, pinning
action-bar.tsxSearch bar, filter buttons, more-actions dropdown
columns.tsxColumnDef array with custom cells
data.tsSample candidate dataset + tree builder
pinning.tsLeft/right column pinning style helpers

Installation

pnpm dlx shadcn@latest add @vital-design/data-table-group-01

This installs the block under src/blocks/data-table-group-01/ and pulls every required primitive automatically.
