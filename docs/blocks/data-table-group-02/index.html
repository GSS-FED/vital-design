Composition

This block is built on the following Vital Design primitives:

  • Avatar, Badge, Button, Card, Checkbox, DropdownMenu, SearchBar, Switch, Table, Tag, Toolbar
  • ChevronDownIcon, ChevronUpIcon, EllipsisIcon
  • @tanstack/react-table for state management

Files

FileDescription
DataTableGroup02.tsxBlock entry — selection, sorting, expand, rail layout
action-bar.tsxSearch bar, filter buttons, more-actions dropdown

data.tsSample emission dataset + tree builder
pinning.tsRail width constants and pinning style helpers

Installation

pnpm dlx shadcn@latest add @vital-design/data-table-group-02

This installs the block under src/blocks/data-table-group-02/ and pulls every required primitive automatically.
