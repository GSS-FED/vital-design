Composition

This block is built on the following Vittal Design primitives:

  • Avatar, Badge, Button, Card, Checkbox, DropdownMenu, SearchBar, Switch, Table, Tag, Toolbar
  • CaretDownIcon, CaretUpIcon, ChevronDownIcon, EllipsisIcon
  • @tanstack/react-table for state management

Files

FileDescription
DataTableGroup02.tsxBlock entry — selection, sorting, expand, rail layout
action-bar.tsxSearch bar, filter buttons, more-actions dropdown
columns.tsxColumnDef array with custom cells
data-table-column-header.tsxSortable column header with caret sort toggle
data.tsSample emission dataset + tree builder
pinning.tsRail widths, column sizing vars, pinning style helpers
resize-handle.tsxDraggable column resize handle with full-height guide
table-rail.tsxSticky chevron/rail cells for grouped rows

Props

PropTypeDefaultDescription
columnResizeMode'onChange' | 'onEnd''onChange''onChange' moves the columns under the pointer. 'onEnd' holds them and commits on release, with the guide line showing where the edge lands — it does no layout work while dragging, so it stays smooth on wide, heavily pinned tables.

Installation

pnpm dlx shadcn@latest add @vital-design/data-table-group-02

This installs the block under src/blocks/data-table-group-02/ and pulls every required primitive automatically.
